### 🔄 [Enterprise Sales ETL Pipeline](#)
`SSIS` `SQL Server` `T-SQL` `Medallion Architecture` `Data Warehousing`

An end-to-end automated ETL pipeline built with SSIS, ingesting distributed branch CSV files into a SQL Server Data Warehouse following **Medallion Architecture** (Bronze → Silver/Gold).

- Automated dynamic file ingestion via a **Foreach Loop Container** — zero manual handling as new branch files arrive.
- Ensured idempotency with an Execute SQL Task that truncates staging tables on every run.
- Resolved flat-file type mismatches with Data Conversion transformations; validated records in real time via a **Lookup Transformation (Full Cache)** against `Dim_Customers`, routing invalid rows to an auditable error destination.
- Computed customer age at point-of-purchase inline using a Derived Column transformation (`DATEDIFF` + type casting), feeding a clean Star Schema `Fact_Sales` table.
